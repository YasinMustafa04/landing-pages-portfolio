## 🚀 Getting Started

<a id="getting-started"></a>

The projects are designed to run locally using a PHP-compatible development environment such as **WAMP, XAMPP, or Laragon**.

### Prerequisites

- **Operating System:** Windows
- **Local Server:** [WAMP Server](https://www.wampserver.com/), XAMPP, or Laragon
- **Browser:** Chrome, Firefox, Edge, or another modern browser
- **Version Control:** Git (optional)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/YasinMustafa04/landing-pages-portfolio.git
```

**2. Navigate to the project directory**

```bash
cd landing-pages-portfolio
```

**3. Move the project into your local server directory**

For WAMP, place the project inside:

```text
C:\wamp64\www\landing-pages-portfolio
```

For XAMPP, use:

```text
C:\xampp\htdocs\landing-pages-portfolio
```

**4. Start your local server**

- Launch WAMP, XAMPP, or Laragon.
- Start the Apache service.
- Make sure the server is running correctly.

**5. Open a project in your browser**

For example:

```text
http://localhost/landing-pages-portfolio/luxury-restaurant.php
```

You can access the other projects by replacing the PHP filename in the URL.
